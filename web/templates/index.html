Converter API

      

        

          POST /api/convert
          
Convert proxy links, subscriptions or configs. JSON body {"input":"...","format":"..."}.

          curl -X POST /api/convert -H 'Content-Type: application/json' -d '{"input":"vless://...","format":"singbox"}'
        

        

          GET /api/extract?input=…
          
Extract share links from a sing-box or mihomo config.

        

        

          GET /api/check?link=…
          
Validate a single proxy link.

        

        

          GET /p/{params}/{url}
          
Fetch a subscription through the proxy with custom device headers.

          /p/android,ua=Happ/3.24.1,hwid=.../https://sub.example.com/abc?format=singbox
        

      


      
Rate limiting

      

        
10 req/min per IP for all endpoints.

        Overlimit → HTTP 429 {"error":"rate limit exceeded"}. A Retry-After header is set.
